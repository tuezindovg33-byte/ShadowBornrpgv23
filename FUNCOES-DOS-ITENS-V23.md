# Funções dos itens — V23

Itens personalizados usam a função configurada pelo Admin; sem função, resgatam 20 moedas.
Equipamentos comprados na loja mantêm seus atributos do catálogo. Os bônus abaixo descrevem o kit de equipamentos em unidades na mochila.

| ID | Função |
| --- | --- |
| `money` | Resgatar 100 moedas. |
| `diamond` | Resgatar 1 diamante. |
| `shadow_fragment` | Trocar por 120 moedas. |
| `shadow_coin` | Trocar por 300 moedas. |
| `honor` | Trocar por 100 moedas. |
| `boss_token` | Trocar por 600 moedas. |
| `guild_point` | Contribuir com 100 XP para sua guilda. |
| `event_medal` | Trocar por 250 moedas. |
| `pocao_vida` | Recupera 40% da vida máxima durante uma partida. |
| `pocao_mana` | Recupera 40 pontos da energia da Ultimate. |
| `pocao_vigor` | Reduz dano recebido em 20% por 5 minutos. |
| `pocao_exp` | Dobra a XP do personagem por 10 minutos. |
| `pergaminho` | Aumenta dano em 20% por 5 minutos. |
| `comida` | Recupera 20% da vida máxima. |
| `elixir` | Recupera toda a vida e a energia da Ultimate. |
| `antidoto` | Remove lentidão e queimadura do personagem. |
| `espada_sombria` | Arma: +8 dano. |
| `armadura_abissal` | Armadura: +60 vida e +5 defesa. |
| `capacete_sombrio` | Capacete: +20 vida e +2 defesa. |
| `botas_sombrias` | Botas: +5% velocidade. |
| `luvas_sombrias` | Luvas: +3 dano. |
| `anel_sombrio` | Anel: +3 dano e +2% crítico. |
| `colar_sombrio` | Colar: +20 vida. |
| `cristal_sombrio` | Converter em 3 Essências Sombrias. |
| `minerio` | Converter em 1 Essência Sombria. |
| `madeira` | Converter em 1 Essência Sombria. |
| `pele` | Converter em 1 Essência Sombria. |
| `ferro` | Converter em 2 Essências Sombrias. |
| `polvora` | Converter em 2 Essências Sombrias. |
| `essencia_sombria` | Consumir para receber 200 XP. |
| `fragmento_alma` | Material para melhorar os Guardiões; preservado na mochila. |
| `bau` | Abrir com 1 Chave. Recebe 100–500 moedas e um item. |
| `chave` | Consumida automaticamente ao abrir um baú. |
| `ovo` | Invocar um Guardião aleatório de NPC; não contém bosses. |
| `mapa_item` | Consultar mapas e capítulos sem consumir o item. |
| `livro` | Estudar: receber 500 XP. |
| `asa` | Aumenta velocidade em 20% por 10 minutos. |
| `reliquia` | Trocar por 1.500 moedas. |
| `ticket_evento` | Ativa XP em dobro por 15 minutos. |

Baús precisam de chave; Fragmentos de Alma continuam disponíveis para upgrades.
Poções de vida/mana/comida/elixir/antídoto são usadas numa partida ativa pelo inventário do menu de pausa.
Bônus temporários renovam a duração, sem multiplicar o mesmo efeito. O jogador deve equipar itens fora da partida.
